# DPCO Evidence and Provenance Model

## 1. Evidence Registry
Evidence records support capability claims across 5 orthogonal dimensions (`PASSPORT_DECLARED`, `TEST_SUITE_PASSED`, `FORMALLY_VERIFIED_INSTANCE`, `FORMALLY_VERIFIED_DOMAIN`, `EMPIRICALLY_VALIDATED`).

## 2. Cryptographic Provenance Ledger
Every pipeline transition is recorded in a tamper-evident SHA-256 blockchain ledger, linking task parameters, execution results, verification outcomes, and artifact content hashes.
